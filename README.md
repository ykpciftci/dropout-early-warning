#### Dropout Early Warning

Spotting the students with potential to dropout matters. These students sometimes can be helped as the trouble they face might be easy to resolve for management. even when these student can not be helped, the data might be useful for management to plan resourse allocation accordingly.

### Data

the dataset we are going to use is called **Predict Students' Dropout and Academic Success** and can be acquired from the [UC Urvine Machine Learning Repository](https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success)

### Setup

You need Python 3.14

```bash
git clone https://github.com/ykpciftci/dropout-early-warning.git
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
Download the dataset, unzip it, and place it at data/raw/data.csv
